# 多源异构数据驱动岗位和能力图谱项目需求摘要

## 项目目标

构建一套“数据采集 -> 岗位发现与定义 -> 能力图谱动态演化 -> 图谱可视化 -> 简历解析 -> 人岗匹配诊断 -> 改进建议与学习路径规划”的闭环系统。

项目面向新一代信息技术领域，重点覆盖人工智能、大数据、智能系统、物联网等方向。系统应解决企业“新兴岗位识别难、人岗匹配度低”和求职者“职业路径不清、技能需求变化快”的问题。

## 核心功能

1. 新岗位发现与定义
   - 从多源数据中识别尚未标准化或正在兴起的新岗位。
   - 生成岗位名称、核心职责、必备技能、加分技能、典型行业应用场景。
   - 支持人工优化与动态更新。

2. 既有岗位能力动态更新
   - 针对既有岗位，例如 Java 开发工程师，识别能力要求变化。
   - 标注新增、删除、修改的能力项。
   - 提供更新说明和数据来源。

3. 全景图谱可视化
   - 展示岗位、能力、技能点、技术栈、级别之间的关系。
   - 粒度需达到“技能点”级别。
   - 支持按技术栈、级别、岗位类型切换视图。

4. 人岗匹配诊断与差距分析
   - 支持简历 PDF/Word 解析。
   - 提取简历技能要素，目标准确率 >= 90%。
   - 支持多维度匹配分析。
   - 输出技能差距、改进建议、学习路径。

5. 动态演化分析
   - 支持岗位和技能需求的时间维度对比。
   - 典型展示：2024 vs 2025 某岗位技能需求变化。
   - 支持未来趋势预测，例如未来 6 个月需求上升技能。

## 创新性要求

1. 多源异构数据清洗和交叉验证机制
   - 至少覆盖 3 类数据源。
   - 为每条数据标记来源和时间戳。
   - 处理招聘数据中的时滞、噪音、抄袭、通胀问题。
   - 建立数据质量评分体系。

2. 图谱 + RAG 融合推理
   - 将岗位能力图谱作为事实基础注入检索增强生成流程。
   - 生成结论需要可回查到图谱事实和原始数据来源。

3. 大模型幻觉防控
   - 基于图谱事实回查校验生成内容。
   - 对缺少来源支撑的能力项标记为待审核。

4. 能力差距可视化
   - 将求职者能力与目标岗位能力要求之间的差距以图谱路径或技能矩阵展示。

## 可验证指标

- 至少 100 条岗位 JD 和测试用例。
- JD 解析准确率 >= 90%。
- 简历提取准确率 >= 90%。
- 人岗匹配准确率 >= 90%。
- 单元测试覆盖率目标 >= 60%。

> ⚠️ **以上准确率指标（JD 解析、简历提取、人岗匹配 >= 90%）为比赛目标值，非当前已达成绩。**
> 当前系统尚未完成双人独立标注评测，人工标注状态为 `pending_annotation`，不得将这些目标值作为生产准确率对外宣传。
> 实际 holdout 诊断数据（24 条，单标注者）：技能 F1=0.8125，分类准确率=0.6667。

## 评分导向

- 完整性 30 分：重点是全流程闭环、部署可运行、核心功能不缺失。
- 技术创新性 25 分：重点是大模型、知识图谱、RAG、动态演化、幻觉防控。
- 用户体验 15 分：重点是图谱交互流畅、差距分析清晰、操作流程简洁。
- 实用价值 30 分：重点是真实数据集、量化指标、企业招聘和职业规划可迁移价值。

## 第一版 MVP 范围

第一版先做可运行闭环，不直接引入重型数据库和模型依赖：

- Java 后端提供 REST API 和领域服务。
- React + TypeScript 前端（`talentmatch-frontend/`）提供岗位图谱、动态演化、人岗匹配、数据质量视图。
- 数据先用内存样例，后续替换为 MySQL、Neo4j、Elasticsearch、向量库和大模型服务。
- 简历解析第一版用文本技能抽取占位，后续接入 OCR、PDF/Word 解析和 NER。
