# Quality benchmarks

- `accuracy_report.json` is the deterministic template regression generated by
  `python scripts/evaluate_accuracy.py`. It detects rule regressions, but is not
  independent evidence of production accuracy.
- `accuracy_holdout_v1.jsonl` is a fixed manually reviewed diagnostic holdout,
  stored independently from `scripts/evaluate_holdout.py`. The evaluator reports
  real errors and category strata in `accuracy_holdout_report.json`.
- `retrieval_qrels_v1.json` contains fixed graded judgements for a pooled search
  result set. With Elasticsearch running, `python scripts/evaluate_retrieval.py`
  reports MRR@10, nDCG@10, and judged coverage.

Both manually reviewed datasets currently have one reviewer. They must be
expanded and independently double-labelled before making production claims.
