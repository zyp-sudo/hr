# 已归档前端（请勿作为正式入口）

此目录集中保存项目的历史前端、早期视觉原型和静态设计稿，仅用于回溯与参考。

当前唯一正式前端位于仓库根目录的 `talentmatch-frontend/`，默认运行端口为 `3000`。

归档内容：

- `frontend/`：历史 Python Web 页面
- `frontend-react/`：早期 React 原型
- `frontend-vue/`：早期 Vue 原型
- `ui-redesign/`：静态改版设计稿
- `TalentMatch-demo.html`：独立静态演示页

除非明确需要验证历史实现，请勿从本目录启动服务或继续开发。
