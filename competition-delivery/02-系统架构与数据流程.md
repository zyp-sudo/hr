## 4. 数据模型

### 4.1 核心领域对象

```text
JobRole (岗位)
  ├── id, name, type, description
  ├── skills: List<SkillRef>
  └── sources: List<SourceRef>

Skill (技能点)
  ├── id, name
  ├── aliases: List<String>

  └── level: String

Capability (能力维度)
  ├── id, name

GraphEdge (图谱边)
  ├── from: NodeId
  ├── to: NodeId
  ├── type: requires | belongs_to | bonus | part_of
  ├── weight: int
  └── confidence: float

EvolutionPoint (演化数据点)
  ├── period: String (YYYY-MM)
  ├── roleId: String
  ├── skill: String
  ├── demand: int
  └── sourceCount: int

MatchResult (匹配结果)
  ├── targetJobId, targetJobName
  ├── score: int (0-100)
  ├── matchedSkills, missingSkills
  ├── dimensions: List<DimensionScore>
  ├── suggestions: List<String>

DataSource (数据来源)
  ├── sourceId, sourceName, sourceType
  ├── trustWeight: float
  ├── status: String
  └── baseUrl, collectionMethod, licenseNote
```

## 5. 增量同步架构

### 5.1 MySQL 同步

```text
1. SHA-256 检测快照文件变化
2. 变化的表 → 载入临时快照表
3. 按主键 + null-safe 行差异比较
4. Upsert 新增/变更行
5. 删除源快照中已不存在的主键
6. 单表对账在一个事务中完成
7. 状态 JSON 通过原子替换发布
```

### 5.2 Elasticsearch 同步

```text
1. 扫描 ES 中的 id 和 sync_hash
2. 计算 MySQL 每行的规范哈希
3. 仅索引新增或 sync_hash 变更的文档
4. 删除 MySQL 中已不存在的 ES 文档
5. 旧记录的 collected_at 更新也可检测
```

### 5.3 Neo4j 同步（全量重算边界）

Neo4j 的 nodes、edges、aliases、trends、graph_versions 是全局聚合快照。源数据变化时触发全量重建——这是文档明确的全量重算边界。

## 8. 公司智能体适配器

### 8.1 定位

公司智能体（Company Agent）是外部企业评分系统的**适配层**——它不是独立的评分引擎，而是为未来接入企业自有人才评分 API 预留的标准化适配接口。

### 8.2 当前状态

| 项目 | 值 | 说明 |
|------|-----|------|
| 环境变量 | `COMPANY_AGENT_ENABLED=false` | 默认禁用 |
| 状态 | **disabled / 待接入** | 不发送任何远程请求 |
| Provider 类型 | `disabled` | 多 Provider 适配器当前仅保留本地确定性评分路径 |

### 8.3 行为约束

1. **未配置时不生成假评分**：当 `COMPANY_AGENT_ENABLED=false` 或未设置 `COMPANY_AGENT_API_URL`、`COMPANY_AGENT_AUTH` 和字段映射协议时，系统不发送远程请求，不返回模拟/随机评分。
2. **本地确定性评分独立展示**：本地规则引擎的匹配评分与公司智能体评分分开展示，前端明确标注数据来源（"本地规则评分" vs "企业系统评分"）。
3. **密钥管理**：后续接入仅通过环境变量（`COMPANY_AGENT_API_KEY`）配置，不写入源码、配置文件或版本控制。

### 8.4 接入前提（全部满足后才启用）

- 企业提供正式 API URL、认证方式和字段协议
- 双方确认评分字段映射（岗位 ID、能力维度、分数范围）
- 在隔离环境完成对接测试
- 通过安全审查（密钥不落盘、日志脱敏、超时与重试策略）

> ⚠️ **不得描述为已正式联调或已投入生产。** 当前交付态不依赖任何外部企业系统，所有评分均为本地确定性计算。
