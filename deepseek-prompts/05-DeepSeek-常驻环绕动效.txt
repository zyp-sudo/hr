项目目录：E:\202676\talentmatch-frontend

一、最终目标

主页 Hero 的元素流必须完成以下运动叙事：

1. 元素流从页面右侧前景进入。
2. 向“人岗匹配 / 智能 / 评估系统”中央标题收束。
3. 到标题区域时切换到标题后景，从文字后面穿过。
4. 从标题左侧重新切回前景。
5. 沿标题下方回旋，形成包围标题的三根并行蓝紫/蓝青丝带。
6. 入场动画结束后，包围效果必须永久保留在主页 Hero 中，不能淡出、不能删除、不能变成空白。

“永久保留”的含义：只要用户仍停留在主页，最终三条轨迹、素材符号和粒子就一直存在；切换路由导致 HomePage 卸载时才正常 cleanup。效果随 Hero 一起滚动，不要做成 fixed 层覆盖后续内容。

三、必须修正和确认的逻辑

关键词：禁止消失

- GSAP timeline 的 onComplete 中禁止执行 overlay.remove()。
- 禁止把 overlayDivRef.current 设为 null，除非组件 cleanup/unmount。
- 禁止在动画末尾把 orbitPaths、frontOrbitPaths、orbitSymbols、orbitDots 的 opacity 动画到 0。
- leading star 和临时细拖尾可以在入场完成后隐藏；三条包围丝带、9 个素材符号、30 个粒子必须保留。
- onComplete 给 overlay 增加 home-intro__overlay--settled 类。

关键词：最终静态布局

- 入场结束后调用 settleOrbitElements()。
- 9 个符号沿三条完整路径均匀错开，不能全部堆在右侧终点。
- 30 个粒子沿路径均匀分布，不能集中成三个点。
- 处于路径进度约 0.18～0.48 的元素放入 backLayer，其他元素放入 frontLayer，保持“从文字后穿过再从左侧穿出”的层级关系。
- 最终符号建议 opacity 0.45～0.65，最终粒子 opacity 0.20～0.45，不能压住标题和说明。
- 最终状态不要继续运行无限 GSAP 动画，不要用 setInterval；保持静态可减少耗电。
- 动画完成后清除 symbol/dot 的 will-change。

关键词：轨迹常驻

- backOrbitPaths 与 frontOrbitPaths 的 strokeDashoffset 最终必须为 0。
- 不允许在 1.7 秒附近把路径 opacity 淡到 0。
- 前景路径应比后景路径略亮，但标题文字必须始终可读。
- 最终三根丝带保持接近的平行间距，不能互相乱穿。

关键词：刷新和重复进入

- 每次刷新主页都重新播放入场，然后进入常驻状态。
- 从其他页面返回主页也重新播放。
- React StrictMode 第一次试挂载必须在 cleanup 中移除，不允许同时存在两套 overlay。
- 动画完成 5 秒后，页面仍应只有 1 个 overlay，而不是 0 个或多个。

关键词：ResizeObserver

- 窗口改变尺寸后更新 back/front SVG path。
- 如果已经 settled，重新调用 settleOrbitElements(newOrbitDs)，让符号和粒子跟随新路径重新分布。
- 不允许 resize 后符号留在旧坐标。

关键词：交互和清理

- overlay、frontLayer、backLayer 均保持 pointer-events:none。
- 标题和按钮继续可点击、可选择、可通过键盘操作。
- HomePage 卸载时才执行 overlay.remove()、ResizeObserver.disconnect()、ctx.revert()。
- 不能留下重复 ScrollTrigger、事件监听器或动画节点。

四、移动端和无障碍

- <=768px 继续隐藏完整轨迹动画，避免标题拥挤；正文必须立即完整显示。
